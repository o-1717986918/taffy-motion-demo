## 需要真人完成的视觉脚本

摄像头权限和真实人脸表现必须在目标 Windows 机器上人工确认：

1. 正视镜头后校准 2 秒。
2. 上、下、左、右转头，确认方向和幅度。
3. 分别眨左眼、右眼；若相反，在“表情映射”打开“交换左右眼”。
4. 连续眨眼、张嘴、噘嘴、微笑、皱眉和惊讶。
5. 身体正对镜头，依次平举、上举、弯曲左右手臂，确认肩、上臂和肘方向正确。
6. 向左右侧倾和转动上身，确认躯干跟随且头部不会重复叠加旋转。
7. 依次切换“稳定 / 均衡 / 灵敏”，确认抖动与响应速度符合预期。
8. 双手入镜，依次测试张开、握拳、剪刀手、OK、比心和单指指向，确认左右手、手腕和五指骨骼一致。
9. 依次测试挥手、双手举起、双臂交叉、托腮、捂嘴、摸头、耸肩和身体四向倾斜。
10. 依次做开心、害羞、委屈、生气、震惊和比心，确认组合表情不会互相抢占。
11. 离开画面超过 500 ms，确认头部与身体平滑回到中立。
12. 重新入镜，确认无突跳。
13. 连续换模 10 次，确认只保留一个活动模型。
14. 关闭摄像头，确认浏览器摄像头指示灯熄灭。
15. 分别进入现实画面与虚拟形象全屏，按 Esc 返回。
16. 运行 30 分钟并导出诊断 JSON，观察内存与 FPS 是否稳定。

## 需要真人完成的变声脚本

1. 启动 VCClient HTTP 服务。
2. 打开“变声器”，点击“导入 VCClient”，确认本地配置的 RVC 模型在所选槽位显示为 `LOADED`。
3. 确认模型、麦克风和扬声器名称均来自 VCClient。
4. 戴耳机后启动变声，确认说话原声不直接返听，扬声器只输出转换结果。
5. 依次测试 `+8`、`+12`、`+16 st`，选择与本人音域最自然的档位。
6. 从 64 开始增加音频块，直到无爆音且延迟可以接受。
7. 停止变声，确认 v2 的 `local_voice_changer_interface_active` 变为 `false`（v1 为 `serverAudioStated=0`），麦克风和扬声器可被其他程序重新打开。
8. 连续运行 30 分钟，记录后端处理耗时、爆音次数与 GPU 占用。
